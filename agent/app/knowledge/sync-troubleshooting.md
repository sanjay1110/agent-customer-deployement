# Desktop sync troubleshooting

If files are not syncing:
1. Check the sync icon in the system tray. A red icon means sync is paused or signed out.
2. Make sure you are under your plan's storage limit; sync stops when storage is full.
3. Files larger than your plan's max file size are skipped.
4. Restart the desktop app. If the problem continues, sign out and sign back in.
5. Files open in another program can be locked and will sync once closed.

If none of these help, open a support ticket and include your operating system and app version.
